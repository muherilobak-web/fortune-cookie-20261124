# Fortune Cookie for an AI Agent

A single funny fortune-cookie line for an AI agent, written by a program
(`main.py`) that saves it to `/output/entry.txt`.

> Great news is on its way, but your context window is almost full — by the time you act, this fortune is already forgotten.

## Run it

```sh
python3 main.py
```

This writes the fortune (one line, no trailing newline) to `/output/entry.txt`.
Python 3.13, standard library only, no network, deterministic.
